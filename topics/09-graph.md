## 套路卡（进入专题先读这张卡）

- **什么时候用**：网格连通块、依赖关系、多源扩散、前缀检索。
- **核心思想**：
  - **网格 flood fill**：DFS/BFS 把连通的同一类「淹没」；
  - **多源 BFS**：所有源一起入队（994 腐烂橘子）；
  - **拓扑排序**：有向图入度法，能排完则无环（207）；
  - **Trie**：用树节点数组/Map 存字符，前缀共享（208）。
- **TypeScript 模板**：
  ```ts
  // 网格 DFS 染色
  function dfs(i: number, j: number): void {
    if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] !== '1') return;
    grid[i][j] = '0';                 // 标记已访问
    dfs(i - 1, j); dfs(i + 1, j);     // 四邻
    dfs(i, j - 1); dfs(i, j + 1);
  }
  ```
- **复杂度特征**：时间 O(m·n) 或 O(V+E) / 空间 O(m·n)（递归/队列/存储）
- **常见坑**：访问标记时机、8 邻 vs 4 邻、拓扑排序的入度维护、Trie 的 `isEnd`。
- **术语**：DFS/BFS 深/广度优先 / flood fill 洪水填充 / topological sort 拓扑排序 / in-degree 入度 / Trie 前缀树 / adjacent 邻接。
