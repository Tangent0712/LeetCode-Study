# 专题 14：贪心算法（Greedy）

> 状态：⬜ ｜ 题数：4 ｜ 面试权重：★★★★☆
> 一句话目标：识别「局部最优可推全局最优」的问题，用一次线性扫描解决。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：每一步的局部最优能保证全局最优，且**不用回头**。
- **核心思想**：维护一个「当前状态」（如最低价、最远可达、当前区间右界），扫描一次更新。
- **TypeScript 模板**：
  ```ts
  // 维护最远可达
  let reach = 0;
  for (let i = 0; i < nums.length; i++) {
    if (i > reach) return false;       // 到不了 i
    reach = Math.max(reach, i + nums[i]);
  }
  ```
- **复杂度特征**：时间 O(n) / 空间 O(1)
- **常见坑**：
  - 贪心**正确性**要能说清（何时贪心不成立需改用 DP）；
  - 45 的「层/跳跃次数」用 BFS 思路理解；
  - 763 要先用哈希记录每个字符最后出现位置。
- **术语**：greedy 贪心 / local optimum 局部最优 / global optimum 全局最优 / reachability 可达性 / interval 区间。
