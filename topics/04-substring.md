# 专题 04：子串（Substring）

> 状态：⬜ ｜ 题数：3 ｜ 面试权重：★★★★☆
> 一句话目标：掌握「前缀和 + 哈希」「单调队列」「可变窗口」三类子串/子数组利器。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：连续子数组的**和 / 最值**，尤其是「和等于 K」「窗口最大值」。
- **核心思想**：
  - 子数组和 → **前缀和 + 哈希**：`pre[j] - pre[i] = K` 即找 `pre[i] = pre[j] - K`；
  - 窗口最值 → **单调队列**（存下标，保持单调）；
  - 覆盖子串 → **可变滑动窗口 + 计数**。
- **TypeScript 模板**：
  ```ts
  // 前缀和 + 哈希
  const cnt = new Map<number, number>();
  cnt.set(0, 1); // 关键：空前缀
  let pre = 0, ans = 0;
  for (const x of nums) {
    pre += x;
    ans += cnt.get(pre - k) ?? 0;
    cnt.set(pre, (cnt.get(pre) ?? 0) + 1);
  }
  ```
- **复杂度特征**：时间 O(n) / 空间 O(n)
- **常见坑**：
  - 忘记 `cnt.set(0, 1)`（漏掉「从下标 0 开始」的子数组）；
  - 单调队列存**下标**而非值，弹出过期下标；
  - 76 的 `valid` 计数维护。
- **术语**：prefix sum 前缀和 / subarray 子数组 / monotonic deque 单调队列 / sliding window 滑动窗口。
