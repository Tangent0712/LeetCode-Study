# 专题 10：回溯（Backtracking）

> 状态：⬜ ｜ 题数：8 ｜ 面试权重：★★★★★
> 一句话目标：用「选择 → 递归 → 撤销」的模板，系统地枚举所有方案。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：要求**枚举所有**方案（排列/组合/子集/分割/棋盘），或找**任一**可行解。
- **核心思想**：决策树上的 DFS；进入分支做选择，回溯时撤销选择。剪枝砍掉不可能的分支。
- **TypeScript 模板**：
  ```ts
  const res: number[][] = [];
  const path: number[] = [];
  function backtrack(start: number): void {
    if (/* 到达叶子/满足条件 */) { res.push([...path]); return; } // 注意拷贝
    for (let i = start; i < candidates.length; i++) {
      if (/* 剪枝 */) continue;
      path.push(candidates[i]);       // 选择
      backtrack(i + 1);               // 递归（排列用 i+1 或用 used）
      path.pop();                     // 撤销
    }
  }
  ```
- **复杂度特征**：时间指数级（O(n·n!) / O(2^n) 等）/ 空间 O(n)（递归深度 + path）
- **常见坑**：
  - `res.push(path)` 必须**深拷贝**（`[...path]`）；
  - 组合类用 `start` 控制顺序避免重复；排列类用 `used` 数组；
  - 含重复元素要先**排序 + 跳过同层重复**；
  - 剪枝条件（如剩余和不足）。
- **术语**：backtracking 回溯 / pruning 剪枝 / permutation 排列 / combination 组合 / subset 子集 / decision tree 决策树。
