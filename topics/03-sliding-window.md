# 专题 03：滑动窗口（Sliding Window）

> 状态：⬜ ｜ 题数：2 ｜ 面试权重：★★★★☆
> 一句话目标：维护一个可伸缩的区间 [l, r]，在线性时间内解决「连续子串/子数组」的极值问题。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：**连续**子数组/子串，求**最长/最短/是否存在**满足某条件的窗口。
- **核心思想**：右指针扩张窗口，窗口不合法时左指针收缩；用哈希表/计数维护窗口状态。
- **TypeScript 模板**：
  ```ts
  let l = 0;
  const win = new Map<string, number>(); // 窗口状态
  for (let r = 0; r < s.length; r++) {
    // 1) 把 s[r] 加入窗口
    // 2) while (窗口不合法) { 移除 s[l]; l++; }
    // 3) 此处窗口合法，更新答案
  }
  ```
- **复杂度特征**：时间 O(n)（l、r 各最多走 n 步）/ 空间 O(k)（字符集大小）
- **常见坑**：
  - 收缩条件写错（应为「不合法就一直缩」）；
  - 求最短时在 while **内部**更新答案，求最长时在 **外部**更新；
  - 字符集大小决定用数组还是 Map。
- **术语**：sliding window 滑动窗口 / expand 扩张 / shrink 收缩 / window state 窗口状态 / substring 子串 / subarray 子数组。
