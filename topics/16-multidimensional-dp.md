# 专题 16：多维动态规划（Multidimensional DP）

> 状态：⬜ ｜ 题数：5 ｜ 面试权重：★★★★☆
> 一句话目标：掌握二维状态 `dp[i][j]`（网格 / 双串）的定义与转移。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：状态由**两个维度**决定——网格坐标 `(i,j)`，或两个字符串的前缀 `(i,j)`。
- **核心思想**：`dp[i][j]` = 「走到 (i,j) / 用 s1 前 i 与 s2 前 j」时的答案。
- **TypeScript 模板**：
  ```ts
  const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));
  // 初始化第 0 行 / 第 0 列
  for (let i = 1; i <= m; i++)
    for (let j = 1; j <= n; j++)
      dp[i][j] = /* 转移 */;
  return dp[m][n];
  ```
- **复杂度特征**：时间 O(m·n) / 空间 O(m·n)（可滚动降维）
- **常见坑**：
  - 初始化第 0 行/列（网格首行首列、双串空前缀）；
  - 下标从 1 开始还是 0 开始要统一；
  - 72/1143 的「删/改/插」三种来源。
- **术语**：2D DP 二维动态规划 / grid DP 网格 DP / LCS 最长公共子序列 / edit distance 编辑距离 / palindrome 回文。
