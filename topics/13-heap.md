# 专题 13：堆（Heap / Priority Queue）

> 状态：⬜ ｜ 题数：3 ｜ 面试权重：★★★★☆
> 一句话目标：动态维护「前 K / 中位数 / 最值」，把每次取最值降到 O(log n)。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：需要**动态**求最大/最小/前 K / 中位数；数据边来边问。
- **核心思想**：二叉堆（完全二叉树），插入/弹出 O(log n)，取堆顶 O(1)。
  - 求「前 K 大」→ 维护**大小为 K 的小顶堆**；
  - 求中位数 → **大顶堆 + 小顶堆** 各存一半。
- **TypeScript 模板**（TS 无内置堆，先手写或用数组 + 排序暴力对比）：
  ```ts
  class MinHeap {
    private a: number[] = [];
    size(): number { return this.a.length; }
    peek(): number { return this.a[0]; }
    push(x: number): void { /* 上浮 */ }
    pop(): number { /* 下沉 */ }
  }
  ```
- **复杂度特征**：单次操作 O(log n)；建堆 O(n)；取顶 O(1) / 空间 O(k) 或 O(n)
- **常见坑**：
  - 大顶堆 vs 小顶堆选反（前 K 大用小顶堆）；
  - TS/JS 无内置优先队列，需手写；
  - 295 的双堆要保持大小差 ≤ 1。
- **术语**：heap 堆 / priority queue 优先队列 / heapify 建堆 / top-k 前 K / median 中位数 / sift up-down 上浮下沉。
