# 专题 17：技巧（Tricks）

> 状态：⬜ ｜ 题数：5 ｜ 面试权重：★★★★☆
> 一句话目标：记住几类「神来之笔」：位运算、摩尔投票、荷兰国旗、原地哈希、下一个排列。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：题目有特殊约束（O(1) 空间 / 线性时间 / 只出现一次等），常规哈希被禁用。
- **核心思想**：
  - **XOR 位运算**：`a ^ a = 0`，找只出现一次的数（136）；
  - **摩尔投票**：多数元素 > n/2，用「票数抵消」（169）；
  - **荷兰国旗 / 三指针**：一次遍历分三色（75）；
  - **原地哈希**：数 x 放到下标 x-1（287 变体、41）；
  - **下一个排列**：从右找升序对 → 交换 → 反转后缀（31）。
- **TypeScript 模板**：
  ```ts
  // 摩尔投票
  let cand = nums[0], count = 0;
  for (const x of nums) {
    if (count === 0) cand = x;
    count += (x === cand ? 1 : -1);
  }
  ```
- **复杂度特征**：多数目标 时间 O(n) / 空间 O(1)
- **常见坑**：XOR 前提（其余元素成对）；摩尔投票只保证出现 > n/2；荷兰国旗三指针边界。
- **术语**：bit manipulation 位运算 / XOR 异或 / Boyer-Moore voting 摩尔投票 / Dutch national flag 荷兰国旗（三路划分）/ in-place hashing 原地哈希。
