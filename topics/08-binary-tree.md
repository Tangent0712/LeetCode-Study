# 专题 08：二叉树（Binary Tree）

> 状态：⬜ ｜ 题数：15 ｜ 面试权重：★★★★★
> 一句话目标：把「递归三序 + 层序 BFS + BST 性质 + 后序返回信息」练成肌肉记忆。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：任何层级 / 递归结构。
- **核心思想**：
  - **递归三序**：前序（处理在下行）、中序（BST 得有序）、后序（利用子树结果）；
  - **层序 BFS**：用队列按层处理（102、199、右视图）；
  - **BST**：中序遍历有序；校验要用**上下界**而不是只比较父节点；
  - **后序返回信息**：如深度、路径和、直径、最大路径和。
- **TypeScript 模板**：
  ```ts
  function dfs(node: TreeNode | null): number {
    if (node === null) return 0;         // 1) 终止
    const l = dfs(node.left);            // 2) 左
    const r = dfs(node.right);           // 3) 右
    return Math.max(l, r) + 1;           // 4) 合并
  }
  ```
- **复杂度特征**：时间 O(n)（每节点访问一次）/ 空间 O(h)（递归栈，h 为高度；最坏 O(n)）
- **常见坑**：
  - 98 校验 BST 用 `(min, max)` 界，不能只比父；
  - 层序要按当前队列长度切分一层；
  - 124 的「最大路径和」返回值与全局答案要分开；
  - 空树 / 单节点。
- **术语**：preorder/inorder/postorder 前/中/后序 / BFS 广度优先 / BST 二叉搜索树 / LCA 最近公共祖先 / diameter 直径 / depth 深度。
