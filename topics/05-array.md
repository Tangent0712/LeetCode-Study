# 专题 05：普通数组（Array）

> 状态：⬜ ｜ 题数：5 ｜ 面试权重：★★★★☆
> 一句话目标：掌握数组上的贪心 / 原地变换 / 区间处理等基本功。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：一维数组的**最值、区间、原地重排、索引映射**。
- **核心思想**：
  - 最大子数组和 → **Kadane / 经典 DP**（负贡献就重新开始）；
  - 区间合并 → 排序后线性扫描；
  - 原地轮转 → 三次反转 / 环状替换；
  - 除自身乘积 → 前缀积 × 后缀积；
  - 缺失正数 → **原地哈希**（把数 x 放到下标 x-1）。
- **TypeScript 模板**：
  ```ts
  // Kadane
  let cur = nums[0], best = nums[0];
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    best = Math.max(best, cur);
  }
  ```
- **复杂度特征**：多数目标 O(n) 时间 / O(1) 额外空间
- **常见坑**：负数、整数溢出（JS 注意 `2**31`）、原地索引映射的「加 n」技巧、边界空数组。
- **术语**：Kadane 算法 / in-place 原地 / interval 区间 / prefix product 前缀积 / cycle rotation 轮转。
