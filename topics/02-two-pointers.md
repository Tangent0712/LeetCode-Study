# 专题 02：双指针（Two Pointers）

> 状态：⬜ ｜ 题数：4 ｜ 面试权重：★★★★☆
> 一句话目标：用两个指针压缩搜索空间，把嵌套循环 O(n²) 降成 O(n)。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：数组/字符串**有序**、需要**两端逼近**、**原地**去重/移动、快慢指针判圈。
- **核心思想**：两个指针按规则移动，每步排除掉一批不可能的答案。
- **TypeScript 模板**：
  ```ts
  // 对撞指针（多用于有序数组）
  let l = 0, r = arr.length - 1;
  while (l < r) {
    // 根据 sum/条件，决定 l++ 还是 r--
    l++; // 或 r--;
  }

  // 快慢指针（原地移动）
  let slow = 0;
  for (let fast = 0; fast < n; fast++) {
    if (/* 满足条件 */) { arr[slow++] = arr[fast]; }
  }
  ```
- **复杂度特征**：时间 O(n)（或 O(n log n) 若需先排序）/ 空间 O(1)
- **常见坑**：
  - 对撞指针**要求有序**（无序要先排序）；
  - 移动哪一侧的判断依据（比较当前两侧）；
  - 去重时「跳过重复」要写成 `while` 而不是 `if`。
- **术语**：two pointers 双指针 / left-right pointers 左右/对撞指针 / fast-slow pointers 快慢指针 / in-place 原地 / two-sum 两数之和。
