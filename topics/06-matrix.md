> 状态：⬜ ｜ 题数：4 ｜ 面试权重：★★★★☆
> 一句话目标：掌握二维网格的「原地标记」与「按层模拟」。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：二维网格的遍历、原地变换、有序矩阵查找。
- **核心思想**：
  - 置零 → 用**首行/首列**当标记位，省掉额外空间；
  - 螺旋 → 维护 `top/bottom/left/right` 四条边界并收缩；
  - 旋转 90° → 先转置再左右翻转（或按四点环状交换）；
  - 有序矩阵查找 → 从**右上角**出发（左小下大）。
- **TypeScript 模板**：
  ```ts
  let top = 0, bottom = m - 1, left = 0, right = n - 1;
  while (top <= bottom && left <= right) {
    // 遍历上边 -> 右边 -> 下边 -> 左边，然后收缩边界
  }
  ```
- **复杂度特征**：目标 O(m·n) 时间 / O(1) 额外空间
- **常见坑**：螺旋的边界收缩顺序、单行/单列退化、原地标记的恢复（首行首列单独处理）。
- **术语**：matrix 矩阵 / transpose 转置 / in-place 原地 / boundary 边界 / spiral 螺旋。
