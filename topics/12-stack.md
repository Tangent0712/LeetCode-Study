# 专题 12：栈（Stack）

> 状态：⬜ ｜ 题数：5 ｜ 面试权重：★★★★☆
> 一句话目标：用 LIFO 与单调栈解决匹配、解码、下一个更值等问题。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：括号匹配、表达式求值、最近相关性，以及「下一个更大/更小元素」。
- **核心思想**：
  - **LIFO 栈**：最近入栈的先处理（20、394）；
  - **辅助栈**：与主栈同步维护最小值（155）；
  - **单调栈**：保持栈内单调，弹出时结算答案（739、84）。
- **TypeScript 模板**：
  ```ts
  // 单调递减栈：找「下一个更大元素」
  const st: number[] = [];               // 存下标
  for (let i = 0; i < n; i++) {
    while (st.length > 0 && a[st[st.length - 1]] < a[i]) {
      const j = st.pop()!;               // a[j] 的下一个更大元素是 a[i]
    }
    st.push(i);
  }
  ```
- **复杂度特征**：时间 O(n)（每个元素最多进出栈一次）/ 空间 O(n)
- **常见坑**：栈存**下标**还是**值**；弹出条件用 `<` 还是 `<=`；84 用哨兵简化边界。
- **术语**：stack 栈 / LIFO 后进先出 / monotonic stack 单调栈 / next greater element 下一个更大元素 / parenthesis 括号。
