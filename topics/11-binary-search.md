# 专题 11：二分查找（Binary Search）

> 状态：⬜ ｜ 题数：6 ｜ 面试权重：★★★★☆
> 一句话目标：把「每次排除一半」的边界写到不出错。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：数组**有序**，或答案具有**单调/二段性**（能用一个判定函数把区间一分为二）。
- **核心思想**：维护一个「答案必在」的区间，每轮排除一半。
- **TypeScript 模板**：
  ```ts
  // 左闭右闭 [l, r]
  let l = 0, r = n - 1;
  while (l <= r) {
    const mid = l + ((r - l) >> 1);   // 防溢出
    if (nums[mid] === target) return mid;
    else if (nums[mid] < target) l = mid + 1;
    else r = mid - 1;
  }
  return -1;
  ```
- **复杂度特征**：时间 O(log n) / 空间 O(1)
- **常见坑**：
  - `mid` 用 `l + (r-l)/2` 防溢出；
  - 循环条件与左右收敛方式必须自洽（`<=` 配 `mid±1`，`<` 配 `mid`）；
  - 旋转数组先判断哪一半有序；
  - 找边界用「左边界/右边界」两套模板。
- **术语**：binary search 二分查找 / lower bound 下界 / upper bound 上界 / monotonic 单调 / pivot 支点 / rotated 旋转。
