# 专题 15：动态规划（Dynamic Programming）

> 状态：⬜ ｜ 题数：10 ｜ 面试权重：★★★★★
> 一句话目标：掌握「状态定义 + 转移方程 + 初始化 + 遍历顺序」四步法。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：问题有**重叠子问题** + **最优子结构**（大问题由小问题最优解拼出）。
- **核心思想**：用 `dp[...]` 记录子问题答案，避免重复计算。
- **TypeScript 模板**：
  ```ts
  const dp = new Array(n + 1).fill(0);
  dp[0] = /* 边界 */;
  for (let i = 1; i <= n; i++) {
    dp[i] = /* 由 dp[i-1] / dp[i-2] / ... 转移 */;
  }
  return dp[n];
  ```
- **复杂度特征**：时间 = 状态数 × 转移代价 / 空间 = 状态数（可用**滚动数组**降到 O(1)）
- **常见坑**：
  - 状态定义含糊 → 先想「dp[i] 代表什么」；
  - 初始化与边界（`dp[0]`、越界）；
  - 遍历顺序（完全背包正序、01 背包倒序）；
  - 152 需同时维护**最大与最小**（负数翻转）。
- **术语**：DP 动态规划 / state 状态 / transition 转移 / memoization 记忆化 / rolling array 滚动数组 / knapsack 背包。
