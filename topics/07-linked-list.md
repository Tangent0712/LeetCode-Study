# 专题 07：链表（Linked List）

> 状态：⬜ ｜ 题数：14 ｜ 面试权重：★★★★★
> 一句话目标：熟练「dummy 哨兵 + 快慢指针 + 指针反转」三件套，链表题不再断链。

---

## 套路卡（进入专题先读这张卡）

- **什么时候用**：节点式线性结构；插入/删除/反转/判圈/合并/缓存设计。
- **核心思想**：
  - **dummy 哨兵节点**：让「头节点也可能被删/改」的情况统一化；
  - **快慢指针**：找中点 / 判环 / 找环入口（Floyd 判圈）；
  - **三指针反转**：`prev / cur / next`，先存 next 再改指向；
  - **递归**：反转、合并、K 组翻转的优雅写法。
- **TypeScript 模板**：
  ```ts
  // 哨兵 + 遍历
  const dummy = new ListNode(0, head);
  let prev: ListNode | null = dummy;
  let cur = head;
  while (cur) {
    const nxt = cur.next; // 先存 next，防断链
    // ... 操作
    cur = nxt;
  }
  return dummy.next;
  ```
- **复杂度特征**：时间 O(n) / 空间 O(1)（递归为 O(n) 栈）
- **常见坑**：
  - 改指针前**必须先存 next**；
  - 空链表 / 单节点边界；
  - 环形链表用快慢指针（2 步 vs 1 步）；
  - 146 需要 `Map + 双向链表`。
- **术语**：dummy node 哨兵节点 / fast-slow pointers 快慢指针 / Floyd cycle detection 判圈 / in-place 原地 / doubly linked list 双向链表 / LRU。
